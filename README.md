# Library Management System
*Collaborative project developed with Johairiya Goling.*

This is a desktop-based application built using Python. It streamlines library operations by managing book inventories, tracking borrowing histories, and organizing student or member records through a graphical user interface.

## Key Features
* **User-Friendly Interface:** Built using Tkinter to provide clean windows, forms, and navigation buttons.
* **Database Integration:** Utilizes MySQL connector to securely link, save, and update member information and book data.
* **PDF Report Generation:** Integrated with ReportLab to generate official printable documents and summaries.

## Tech Stack Used
* **Programming Language:** Python
* **GUI Framework:** Tkinter
* **Database Management:** MySQL
* **Reporting Tools:** ReportLab (for PDF generation)
